## 裁决

### 1. 挂载（canonical 表既有行，零文本变更）

- Task 4/5 资源路由（cases / dossiers / conversations，A2 交付、QA 以"exactly as the Contract Lead will"的私有装配验证）正式挂入 `workspace_router`，覆盖 canonical 表 §核心 API 已列出的 subjects/cases/candidates/messages/quick-analyses 行。
- 新实现两组 canonical 既有行：
  - `GET /cases/{decisionCaseId}/reports` 与 `GET /cases/{decisionCaseId}/reports/{reportId}`（ReportArtifact 读投影；list 为 summary，detail 含 `structuredContent`+`validation`）；
  - `GET /simulations/{graphId}/versions` 与 `GET /simulations/{graphId}/versions/{graphVersionId}`（GraphVersion 读投影；detail 含 nodes+edges）。

### 2. 新增两行 canonical 面（本 CCR 的唯一文本变更）

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/api/workspaces/{workspaceId}/cases/{decisionCaseId}/analyses` | 按创建时间倒序列出该 Case 的 AnalysisRun 锚点（anchor 投影：runId/charterId/level/status/caseVersion/时间戳；完整状态仍走 run 状态路由） |
| `GET` | `/api/workspaces/{workspaceId}/cases/{decisionCaseId}/simulations` | 列出该 Case 的因果图锚点（graphId/title/currentGraphVersionId/reportArtifactId） |

两行均为 GET-only anchor 投影，不引入新对象形状，只解决"从 Case 键入已挂载读面"的解析缺口。

### 3. 错误纪律

全部新读面沿用 §8 反枚举：任何 scope 否定（跨租户、幽灵 id、跨 case 报告、跨 graph 版本、同租户跨 scope 混用）坍缩为统一 `CASE_NOT_FOUND` 信封；未知报告 status 过滤返回诚实空页而非枚举 oracle。安全读不携带 CSRF（10-api CSRF 范围澄清）。

### 4. MOUNT-02 Addendum A1 §A1-⑥ audit binding — CLOSED

- 绑定点 = worker VALIDATING 阶段（Task 10 handoff 语义："full gate re-runs merged lens validators per artifact"）：full run 在 executor 验证结论之外必须通过 `audit_full_run_lens_set`，`referenced_artifact_ids` 取 `run.strategic_lens_artifact_ids` **原样传入**（exact-equality 与一切归一化问题属审计方，调用方禁做 parse/normalize/dedup/reorder——tripwire `test_lens_artifact_ids_pass_through_verbatim` 保持绿）。
- `frozen_lens_types` 取冻结 Charter 的 `required_strategic_lens_types`。
- 审计不 ok ⇒ `passed=False` ⇒ blocked；reason codes 以 `{"code", "source": "lens_set_audit"}` 并入 blocked 事件 findings。
- focused run 零 lens 面：审计不执行。
- worker 测试改造（披露）：编排测试注入 recording audit stub（钉 as-is 传参合同），真实审计语义仍由 `tests/test_analysis_quality_gate.py` 全覆盖；新增红灯 `test_real_audit_blocks_full_run_when_persisted_set_is_corrupt`（默认真实审计 + 未持久化 lens 行 ⇒ blocked，executor 的 passed 无法越过审计）。
