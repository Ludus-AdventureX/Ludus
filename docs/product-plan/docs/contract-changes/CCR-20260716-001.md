# CCR-20260716-001: 自定义影响因素与即时实验预览

- Status: accepted
- Requested by: product contract completion task
- Contract owner: Contract/Integration Lead
- Related task: Task 12 / Task 13 / Task 13A

## Reason

P0 沙盘需要允许用户在完整因果模型中自行添加业务影响因素，并及时观察其对建议、影响路径和敏感性的作用。原合同只规定编辑既有节点/边，没有定义自然语言候选、人工关系审阅、工作副本并发和即时预览与正式 SimulationRun 的边界。

## Canonical Impact

- 06-data-model.md: 新增 FactorAuthorship、FactorEvidenceStatus、FactorControllability、GraphWorkingCopy、FactorCandidate、RelationshipCandidate、ExperimentPreview，并扩展节点/边字段。
- 10-api-and-events.md: 新增 working-copy、factor-candidate、preview 路由，以及事件和错误码。
- Event/error/status impact: 新增 `graph.factor_candidate.created`、`graph.working_copy.updated`、`simulation.preview.ready|failed`；新增 revision、factor、relationship、preview 错误。

同时同步 `09/11/13/14/17/18/24`、README、`decision-lab/AGENTS.md` 和方法 manifest。

## Compatibility

- Backward compatible: API schema additive，但 CausalNode/CausalEdge 持久化字段需要 migration 和 fixture 回填。
- Migration required: 为节点/边补 `authorship`、`evidence_status`、`controllability`，创建 working copy/candidate/preview 所需表或短生命周期存储。
- Fixture migration: 现有生成节点/边回填 `authorship=generated`；按证据映射 supported/conditional/assumed/unknown；节点回填 controllability。
- Generated client impact: 需要重新生成 OpenAPI snapshot、TypeScript types 和 client。

## Proposed Change

用户只在完整模型中按需输入因素。系统先产生可审阅候选，不直接写图；用户逐项确认、修改或否决节点和建议关系，接受结果进入 revision 工作副本。工作副本可以生成确定性 ExperimentPreview，但预览不能用于正式决定、报告或推荐。正式运行仍要求保存不可变 GraphVersion、完成确认并主动创建 formal SimulationRun。

## Validation

- Contract tests: 候选字段、禁止 decision、缺证据默认状态、关系审阅、revision conflict、stale preview、preview 正式引用拒绝、formal confirmed 门。
- OpenAPI drift check: 实现阶段重新生成并运行 `pnpm contracts:check`（以仓库最终脚本为准）。
- Rollback: 禁用 custom factor feature flag；保留既有 GraphVersion 和 SimulationRun，废弃工作副本不删除历史。
